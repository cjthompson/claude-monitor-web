claude-monitor
GitHub

Monitor, manage, and automate your Claude Code sessions.

Follow live activity, control permission approvals, and track subagents from one terminal dashboard. Save session hand-offs and rotate sessions with context to pick up where you left off. Mirror iTerm2 panes on macOS, or use simple tabbed mode on Linux and other terminals.

Features

Auto-accept permissions ALLOWED

Permission prompts are automatically accepted so sessions run hands-free. No more switching between panes to approve every Bash, Edit, or Write.

Per-pane mode control MANUAL

Toggle individual panes between auto and manual mode, or use the global toggle. Click a panel's status bar or press m on a focused panel.

Persistent session hand-offs

Keep prompts, files touched, git branch state, agent activity, and open questions together. Enable hand-off capture in Settings, then browse the Hand-off tab, CLI, or Markdown digests when you return.

Session rotation OPT-IN

Clear or compact an exact iTerm2 session and carry forward a bounded summary. Rotate on demand or after configurable silence; automatic rotation defers pane input during permission requests and questions. Outside iTerm2, capture stays local.

Session summaries

Open a session's saved summary from its pane title. Captured facts stay local by default. Optional LLM summaries add a goal, stopping point, and next steps; enabling them sends session excerpts to your configured provider.

Git worktree detection WT:

Recognize sessions running in git worktrees through distinct titles and styling. Keep parallel branches easy to identify alongside your other sessions.

iTerm2 layout mirroring

Mirror split panes and multiple tabs with proportional sizing. New and closed panes are detected every three seconds while event history, panel state, active tab, and focus are preserved.

Simple mode --simple

Tabbed TUI that works on any platform without iTerm2. Auto-detects sessions via the event log. Runs automatically outside iTerm2 or on Linux.

Agent tracking AGENT+

Tracks subagent lifecycle per session with active counts, type breakdowns, and completion totals. Know exactly what's running where.

Resizable dashboard

Grow or shrink the dashboard pane with = and -. Minimize to a one-line summary with d. Height persists across restarts.

API usage bar 55%

Live Anthropic API quota utilization with 5-hour and 7-day progress bars, color coding, and reset countdowns. OAuth token from Keychain or env var.

Command palette & 20 themes

Quick access to all commands via Ctrl+P. Choose from 20 themes including dracula, catppuccin, nord, gruvbox, tokyo-night, and more.

Local HTTP API :17233

Connect external tools to the localhost API for health checks, structured JSON state, and PNG or SVG screenshots of the dashboard.

Credential management

Inspect, refresh, and import Claude Code OAuth credentials in the macOS Keychain with a companion CLI. Transfer credentials between machines using an encrypted, authenticated connection and a shared passphrase.

Install

Terminal
$ git clone https://github.com/cjthompson/claude-monitor.git $ cd claude-monitor $ python3 install.py $ claude-monitor # or ./run.sh for auto-restart
macOS or Linux iTerm2 (optional) Python 3.12+ Claude Code

The installer creates a virtual environment, installs companion commands, and asks before configuring Claude Code hooks. Make sure ~/.local/bin is on your PATH.

For pane mirroring and live session rotation, enable iTerm2's Python API on macOS. Other terminals use simple mode automatically, or run claude-monitor --simple. Hand-off capture and automatic rotation are off by default; enable them in Settings. See the installation guide for details.
